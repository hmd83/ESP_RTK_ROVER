Seeed Studio XIAO ESP32C6 — BLE

Prebuilt firmware v1.0.0. Advertises as ESP32-RTK-XXXX over BLE (Nordic UART), configures the K803 as an RTK rover on every boot. Works with SW Maps, QField, Mergin Maps and Mapit GIS on Android and iOS.

⚠️ Your browser cannot flash. Use Chrome or Edge on desktop — Safari and Firefox have no Web Serial. ⚠️ This page must be served over HTTPS to flash.
  1. Disconnect the GNSS harness — flash the board on its own.
  2. Plug the XIAO into USB-C with a data cable.
  3. Click Connect and pick the serial port.
  4. If no port appears: hold BOOT (B), tap RESET (R), release BOOT, retry.
  5. Install, then open Logs & Console to watch the first boot.

Chrome or Edge on desktop. The XIAO uses native USB — no driver needed.

Build from source

ESP32 DevKitC — Bluetooth Classic SPP or BLE

No prebuilt image on purpose. "ESP32 DevKitC" covers a lot of different boards, and a one-size image would brick or silently misbehave on some of them:

  • WROOM vs WROVER — GPIO16/17 carry the GNSS UART on WROOM, but are consumed by PSRAM on WROVER. Different pins, so a different build.
  • SPP vs BLE — two different transports, two different firmwares.
  • Partition layout — the SPP build needs huge_app.csv; a mismatch against whatever is already on your flash boot-loops.
  • Flash size and USB bridge vary between clones.

Building takes two commands and picks the right settings for your board: 

git clone https://github.com/hmd83/ESP_RTK_ROVER.git
cd ESP_RTK_ROVER
pio run -e esp32dev_spp -t upload    # Bluetooth Classic SPP
pio run -e esp32dev_ble -t upload    # BLE
